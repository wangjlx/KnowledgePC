# 知识库 功能设计文档

## 1. 概述

**项目名称**: 知识库 (Knowledge Base)

**项目定位**: 个人/团队知识管理平台，实现工作记录、任务经验、技能学习的结构化管理和知识资产化。

**技术架构**:
```
┌─────────────────────────────────────┐
│        Browser (Chrome/Edge)        │
│   HTML + CSS + JavaScript 单页应用   │
├─────────────────────────────────────┤
│       HTTP 服务器 (ServerSocket)     │
│         Java REST API 层            │
├─────────────────────────────────────┤
│       SQLite 数据库 (本地存储)        │
│         DatabaseHelper              │
└─────────────────────────────────────┘
```

**核心原则**: 离线优先，所有数据本地存储，保障隐私安全。

### 2.2 功能关系网络

| 子功能 | 前置依赖 | 关联关系 |
|--------|----------|----------|
| 知识条目管理 | 无 | 核心实体，被所有功能引用 |
| 工作记录管理 | 无 | 可转化为知识条目 |
| 标签管理 | 无 | 被条目和记录引用 |
| 双链关联 | 知识条目管理 | 基于条目之间建立链接 |
| 版本管理 | 知识条目管理 | 追踪条目内容变更历史 |
| 智能检索 | 知识条目管理、标签管理 | 搜索标题+内容+标签+时间 |
| 知识图谱 | 知识条目管理、双链关联 | 可视化展示条目关联网络 |
| 数据管理 | 所有功能 | 导入导出备份 |
| 操作日志 | 数据管理、知识条目管理、工作记录管理 | 记录导出/导入和创建操作 |

### 2.3 用户角色与权限

| 角色 | 说明 |
|------|------|
| admin | 管理员：查看所有数据，访问数据管理、后台管理 |
| user | 普通用户：仅查看自己创建的工作记录，查看所有知识条目 |

- 认证方式：用户名 + 密码（PBKDF2-HmacSHA256 哈希，120k 迭代+随机盐；历史无盐 SHA-256 哈希在该用户登录成功时透明升级），Session Token（24 小时滑动过期，重启失效）
- 默认管理员：用户名 `admin`，口令经用户环境变量 `KNOWLEDGE_ADMIN_PASS` 提供（新库首次初始化取 `KNOWLEDGE_SEED_ADMIN_PASSWORD`（≥8 位），未设置则随机生成并输出到启动日志；不预设公开默认口令）
- 认证传递：优先 `Authorization: Bearer <token>` 请求头；兼容旧 `?token=` 查询参数
- 密码策略：注册/建号/改密均要求 ≥8 位且同时包含字母和数字
- 所有 API 支持 `?source=web|mobile` 参数标识请求来源（默认 web）

├─────────────┤

├─────────────┤

> **批量操作**: 知识条目列表和工作记录列表支持通过勾选复选框进入批量模式，可批量执行归档、删除、标签操作，删除操作需二次确认对话框。
> **附件系统**: 编辑器及详情页支持文件附件上传/下载/删除管理，附件区域位于删除按钮与内容正文之间。

## 3. 详细功能设计

### 3.1 知识条目管理

- **功能描述**: 知识资产的核心载体，支持 Markdown 格式的内容编辑，自动生成页面大纲
- **类型分类**: 笔记(note)、技能(skill)、任务(task)、想法(idea)、文章(article)
- **属性**: 标题、内容、摘要、类型、重要性(0-5星)、状态(活跃/归档)、创建人(created_by)
- **支持操作**: 创建、编辑、删除、收藏、归档、分享、导出(.md/.txt/.doc)
- **大纲导航**: Markdown 标题自动提取为左侧大纲，支持隐藏/展开
- **分享功能**: 生成唯一条目分享链接（LAN IP），同一条目重复点击返回相同链接，支持停用/重新启用
- **导出**: 支持 Markdown(.md)、纯文本(.txt)、Word 兼容 HTML(.doc) 三种格式，通过原生 `<select>` 下拉选择
- **标签筛选（v1.6.0）**: 标签下拉按多级分组树形展示（递归缩进，父标签带 ▾ 标记）；选中任意分组父标签时，自动匹配其**全部后代标签**下的条目（后端 `/api/entries?tag=` 及 `/api/search?tag=` 做标签树递归匹配，SQL 用 `tag_id IN (子树id集合)`），筛选框 `min-width:200px`
- **接口**: `GET/POST /api/entries`, `GET/PUT/DELETE /api/entries/:id`

### 3.2 工作记录管理

- **功能描述**: 日常碎片化工作记录，按用户隔离
- **类型分类**: 日记(daily)、会议(meeting)、想法(idea)、笔记(note)、任务(task)
- **属性**: 标题、内容、类型、重要性(0-5星)、状态、创建人(created_by)
- **支持操作**: 创建、编辑、删除、转为知识条目、导出(.md/.txt)
- **大纲导航**: Markdown 标题自动提取为左侧大纲，支持隐藏/展开
- **权限控制**: 管理员查看所有记录，普通用户仅查看自己创建的记录
- **转为条目**: 记录详情页提供「📝 转为知识条目」按钮，一键将工作记录转化为知识条目，内容自动复制到新条目，可在新标签页查看/编辑
- **标签筛选（v1.6.0）**: 列表页新增标签下拉筛选框（多级树形），选中分组父标签时匹配其全部后代标签下的记录（后端 `/api/records?tag=` 标签树匹配，同 entries 逻辑）
- **接口**: `GET/POST /api/records`, `GET/PUT/DELETE /api/records/:id`

### 3.3 双链关联

- **功能描述**: 知识条目之间可相互引用（类似 Roam Research / Obsidian）
- **关联类型**: 引用(reference)、依赖(dependency)、相关(related)
- **双向展示**: 显示当前条目的出链(引用了谁)和入链(被谁引用)
- **接口**: `GET/POST /api/entries/:id/links`, `GET /api/entries/:id/backlinks`

### 3.4 版本管理

- **功能描述**: 知识内容修改保留历史版本，支持追溯变更记录
- **版本策略**: 每次保存自动生成新版本号(递增)
- **变更摘要**: 记录每次变更的简要说明
- **接口**: `GET /api/entries/:id/versions`

### 3.5 标签管理

- **功能描述**: 标签分类体系，支持条目标注、筛选和分组管理
- **属性**: 名称、颜色(用于图谱展示)、父标签(分组)
- **分组管理 (v1.6.0)**: `tags.parent_id` 定义父标签；父标签下挂子标签形成树形层级
  - 创建/编辑标签时可选择父标签；父标签不能是自己的子标签（防循环）；删除父标签时子标签自动回到顶级
  - 前端展示: 标签管理页树形缩进（▾ 分组标记 + 子标签计数）；所有标签下拉框按 optgroup 分组显示层级
- **自动创建**: 添加条目时输入不存在标签名会自动创建
- **接口**: `GET/POST /api/tags`, `GET/PUT/DELETE /api/tags/:id`（POST/PUT 支持 `parent_id`）

### 3.6 智能检索

- **功能描述**: 全文搜索 + 标签筛选 + 时间范围组合查询
- **搜索范围**: 知识条目(标题+内容+摘要) + 工作记录(标题+内容)
- **筛选维度**: 类型、标签、日期范围、收藏状态
- **标签筛选**: 标签下拉多级树形结构，选中分组父标签时匹配其全部后代标签条目（v1.6.0）
- **接口**: `GET /api/search?q=&tag=&type=&date_from=&date_to=`

### 3.7 知识图谱

- **功能描述**: 可视化知识关联网络，直观展示知识点之间的连接关系
- **渲染方式**: Canvas 画布绘制节点和边
- **交互**: 拖拽调整布局、Shift+拖拽框选多节点、拖动选中组整体平移、双击查看详情、滚轮缩放、空白拖拽平移、缩放控件（−/百分比/+/重置）
- **多选与组拖拽（v1.7.0）**: `selected`(Set) 保存选中节点；Shift+空白拖拽画矩形选区（屏幕坐标判定命中，任意缩放/平移下所见即所选框），多次框选追加；组拖拽记录组内各节点起始世界坐标，按世界坐标位移整体同步移动，松开防抖保存全量布局；单击空白/Esc 清空选区
- **视图变换（v1.7.0）**: 引入相机变换（camera = translate + scale），节点统一存**世界坐标**，渲染时经相机变换到屏幕坐标；缩放=1 时与旧版像素坐标一致，`graph_layouts` 历史数据零迁移兼容。缩放/平移视图状态存 localStorage 本地记忆，不影响服务端布局数据
- **布局保存（v1.6.0）**: 拖拽结束后防抖 400ms 自动保存到 `graph_layouts` 表（保存的始终是世界坐标），再次打开图谱时节点按保存位置恢复；未保存过或坐标非法（非数值/超出护栏 ±5000）时回落环形自动布局。**负坐标合法**（节点可拖出画布/原点，v1.8.1 起不再误判"越界"而丢弃位置）
- **布局边界护栏（v1.8.2）**: 护栏常量 `WORLD_GUARD = 5000` 三处统一——①加载校验（超出回落环形）；②画布绘制红色虚线框 + 左上角「布局边界 ±5000」标注（随缩放/平移变换，缩小视图可见全貌）；③拖拽钳制 `clampWorld()`（单节点与组拖拽均被挡在边界内）。三者同源，保证"框内位置必可保存、可保存位置必在框内"
- **节点颜色**: 按条目类型区分颜色
- **接口**: `GET /api/graph`, `GET/POST /api/graph/layout`

### 3.8 数据管理

- **功能描述**: 数据备份、恢复与 KB 目录导入
- **导出格式**: JSON 文件（包含所有条目、记录、标签、关联）
- **导入**: 从 JSON 文件恢复数据（合并模式）
- **KB 目录导入 (v1.6.0)**: `POST /api/import/kb?path=<kbRoot>` 扫描 `D:\1、天翼云盘同步盘\15285514095\KB\` 目录增量导入
  - **目录映射**: `wiki\`→note(个人知识)、`external-wiki\`→article(外部知识)、`team-wiki\`→note(团队知识)、`skills\`→skill、`outputs\`→日报、`team-outputs\`→团队日报、`raw\`→日志、`external-raw\`→资料；`AIRAW\` 经 `raw\` 扫描覆盖
  - **增量去重**: 按标题(文件名去扩展名)匹配，已存在则跳过（不新增、不删除）；修复含乱码(U+FFFD)的旧记录
  - **变更同步 (v1.8.0)**: 已存在条目/记录记录其 KB 源文件相对路径 `kb_source` 与修改时间 `kb_mtime`（毫秒时间戳）。重新导入时若源文件修改时间晚于平台记录值（或平台记录为空/首次同步、或旧内容含乱码），则**覆盖更新**内容与摘要，并重新解析双链；否则跳过。即"KB 源文件更新时间变化 → 重新同步到平台"
  - **编码兼容**: `readKbText` 优先严格 UTF-8 解码，失败回退 GB18030
  - **双链解析**: `[[页面名]]` 语法在导入时建立条目关联
  - **返回统计**: `entries_new / entries_skip / records_new / records_skip / entries_updated / records_updated / relinks / links / tags / errors`
  - **relinks**: `?relinks=1` 参数强制清空并重建所有条目的双链（修复历史遗漏、路径式链接 `[[目录/标题]]`、手动新增链接未回写KB等场景）
- **接口**: `GET /api/export`, `POST /api/import`, `POST /api/import/kb`

### 3.9 附件管理

- **功能描述**: 知识条目和工作记录的文件附件管理，支持任意类型文件上传、下载和删除
- **上传限制**: 单文件大小不超过 50MB，支持批量上传
- **存储方式**: 文件存储在 `data/attachments/` 目录，按 `source_type/source_id/` 组织
- **关联范围**: 可关联到知识条目（entry）和工作记录（record）
- **显示位置**: 详情页中附件区域位于删除按钮与正文内容之间
- **操作权限**: 仅创建者可删除自己的附件
- **接口**: `GET/POST /api/attachments`, `DELETE /api/attachments/:id`

### 3.10 批量操作

- **功能描述**: 知识条目列表和工作记录列表支持批量操作模式
- **进入方式**: 点击列表顶部的「批量模式」开关或批量选择按钮，列表左侧出现复选框
- **操作类型**:
  - **批量归档**: 将选中的条目/记录状态设为 archived
  - **批量删除**: 删除选中的条目/记录，弹出确认对话框要求二次确认
  - **批量标签**: 为选中的条目/记录批量添加或移除标签，标签下拉选默认显示"全部标签..."
- **可视反馈**: 选中项高亮显示，底部批量操作栏显示已选数量
- **接口**: `POST /api/entries/batch`, `POST /api/records/batch`

### 3.11 局域网数据交换（PC-手机同步）

- **功能描述**: 支持 PC 端与手机端在同一局域网内进行数据同步
- **同步方式**:
  - **PC 端作为服务端**: 手机端通过局域网 IP 连接 PC 端服务，进行数据导出（手机拉取 PC 数据）和导入（手机推送数据到 PC）
  - **手机端远程登录**: 手机端可通过局域网 IP + 端口远程登录 PC 端，获取同数据权限
- **接口**:
  - `GET /api/remote/export` — 远程导出数据
  - `POST /api/remote/import` — 远程导入数据
  - `POST /api/remote/login` — 远程登录认证
  - `POST /api/remote/createEntry` — 远程创建条目
  - `POST /api/remote/createRecord` — 远程创建记录
- **同步架构**:
  ```
  ┌──────────┐    HTTP (局域网)    ┌──────────┐
  │  PC 端    │ ◄──────────────►  │  手机端   │
  │ (服务端)  │    192.168.x.x    │ (客户端)  │
  │ :8080     │                   │           │
  └──────────┘                   └──────────┘
  ```
- **安全**: 远程操作需登录认证，Token 鉴权

### 3.12 操作日志

- **功能描述**: 记录数据管理相关操作，便于审计追溯
- **记录范围**:
  - 数据导出操作（记录操作用户、时间、数据量）
  - 数据导入操作（记录操作用户、时间、导入条目数）
  - 知识条目创建操作（记录创建人、时间、条目标题、来源）
  - 工作记录创建操作（记录创建人、时间、记录标题、来源）
- **来源追踪**: 每条日志记录操作来源（web 或 mobile），通过 `?source=` 参数传递
- **接口**: `GET /api/oplogs`, `DELETE /api/oplogs`

### 3.13 条目分享

- **功能描述**: 为知识条目生成唯一分享链接，支持外部只读访问
- **分享页面**: 独立的 HTML 页面（`share.html`），含 Markdown 渲染、大纲导航（左侧）、作者显示、导出下拉（.md/.txt/.doc）
- **链接固定**: 同一条目重复点击分享返回同一链接，不会重新生成 token
- **链接格式**: `http://{LAN_IP}:8080/share/{32位hex_token}`（v1.8.4 由 16 位提升至 32 位增强熵）
- **分享状态**: 列表和详情页显示分享状态标签（未分享/已分享/已停用）
- **生命周期**: 可创建（POST，如有活跃分享直接返回）、查看状态（GET）、停用（DELETE，软删除设 is_active=0）
- **接口**:
  - `POST /api/entries/:id/share` — 创建/重新启用分享，返回 share_url
  - `GET /api/entries/:id/share` — 获取当前分享状态和 URL
  - `DELETE /api/entries/:id/share` — 停用分享
  - `GET /api/share/:token` — 公开分享数据接口（无需认证）

### 3.14 分享页面导出

- **功能描述**: 分享页面支持导出条目为多种格式
- **导出格式**: .md（Markdown 源码）、.txt（纯文本）、.doc（Word 兼容 HTML）
- **触发方式**: 顶栏右侧「📥 导出」原生 `<select>` 下拉选择
- **数据来源**: 直接使用页面已加载的条目数据，无需额外 API 请求

## 4. API 接口一览

| 方法 | 路径 | 功能 |
|------|------|------|
| POST | /api/auth/register | 用户注册 |
| POST | /api/auth/login | 用户登录，返回 token |
| GET | /api/auth/verify | 验证 token 有效性 |
| GET | /api/entries | 获取知识条目列表 |
| POST | /api/entries | 创建知识条目 |
| GET | /api/entries/:id | 获取条目详情 |

## 5. 环境与构建

| 环境 | 版本/路径 |
|------|-----------|
| JDK | 17+ (自动检测: JAVA_HOME/PATH) |
| Gradle | 8.2（网络受限时可手动编译） |
| Java 编译选项 | VERSION_11 (sourceCompatibility / targetCompatibility) |
| 依赖 | sqlite-jdbc-3.45.1.0, json-20231013, slf4j-2.0.9 |

**方式一：一键脚本（推荐，自动检测 JDK）**

项目根目录提供跨平台启动/编译脚本，自动检测系统中可用的 JDK：

```bash
# Windows
compile.bat    # 编译源码
start.bat      # 启动服务

# Linux / macOS
bash compile.sh
bash start.sh
```

> 脚本会依次检测 `JAVA_HOME` → `PATH` 中的 `java`/`javac` → 常见安装路径。若系统中安装了多个 JDK，可通过 `~/.knowledge-java.conf` 配置文件指定路径。

**方式二：手动编译（无网络依赖）**

```bash
# 1. 编译
javac -encoding UTF-8 -d build/classes/java/main -cp "build/libs/sqlite-jdbc-3.45.1.0.jar;build/libs/json-20231013.jar" src/main/java/com/knowledge/*.java

# 2. 启动
java -cp "build/classes/java/main;build/libs/sqlite-jdbc-3.45.1.0.jar;build/libs/json-20231013.jar;build/libs/slf4j-api-2.0.9.jar;build/libs/slf4j-simple-2.0.9.jar" com.knowledge.KnowledgeServer 8080
```

**方式三：Gradle 构建（需网络）**

```bash
gradlew.bat :server:installDist --no-daemon
server\build\install\server\bin\server.bat
```

**依赖 JAR 下载地址**（放置于 `server/build/libs/`）:
- https://repo1.maven.org/maven2/org/xerial/sqlite-jdbc/3.45.1.0/sqlite-jdbc-3.45.1.0.jar
- https://repo1.maven.org/maven2/org/json/json/20231013/json-20231013.jar
- https://repo1.maven.org/maven2/org/slf4j/slf4j-api/2.0.9/slf4j-api-2.0.9.jar
- https://repo1.maven.org/maven2/org/slf4j/slf4j-simple/2.0.9/slf4j-simple-2.0.9.jar

**访问地址**: http://127.0.0.1:8080
