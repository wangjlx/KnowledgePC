# 知识库 操作手册

## 1. 快速开始

### 1.1 启动服务

**方式一：一键脚本（推荐，自动检测 JDK）**

项目根目录提供跨平台脚本，自动检测系统中可用的 JDK：

```bash
# Windows — 编译后启动
compile.bat
start.bat

# Linux / macOS
bash compile.sh
bash start.sh
```

> 脚本自动检测 `JAVA_HOME` → `PATH` 中的 `java`/`javac` → 常见安装路径。首次运行建议先执行 `compile.bat` 编译源码。

**方式二：手动编译（无网络依赖）**

确保 `server/build/libs/` 目录下有依赖 JAR 文件，然后执行：

```bash
javac -encoding UTF-8 -d build/classes/java/main -cp "build/libs/sqlite-jdbc-3.45.1.0.jar;build/libs/json-20231013.jar" src/main/java/com/knowledge/*.java
java -cp "build/classes/java/main;build/libs/sqlite-jdbc-3.45.1.0.jar;build/libs/json-20231013.jar;build/libs/slf4j-api-2.0.9.jar;build/libs/slf4j-simple-2.0.9.jar" com.knowledge.KnowledgeServer 8080
```

**方式三：Gradle 构建（需网络）**

```bash
gradlew.bat :server:installDist --no-daemon
server\build\install\server\bin\server.bat
```

启动后控制台输出：
```
Server started on http://127.0.0.1:8080
Knowledge Server started
Web UI: http://127.0.0.1:8080
API:    http://127.0.0.1:8080/api/stats
```

### 1.2 访问

打开浏览器访问 **http://127.0.0.1:8080**。

系统自动初始化数据库并填充示例数据。

#### 开机自启动（可选，v1.7.1）

本机已配置计划任务 `KnowledgePC-AutoStart`（登录时触发）: 自动启动服务并打开浏览器。手动管理:

```bat
schtasks /Run    /TN "KnowledgePC-AutoStart"   :: 立即执行
schtasks /Delete /TN "KnowledgePC-AutoStart" /F :: 取消自启
```

### 1.3 登录

平台不预设公开默认口令。管理员口令通过本机用户环境变量 `KNOWLEDGE_ADMIN_PASS` 提供（首次安装新库时，随机初始口令输出在启动日志中）。登录后可在「后台管理」页面管理其他用户账户。

### 1.4 停止服务

按 `Ctrl+C` 关闭服务窗口，或直接关闭命令行窗口。

## 3. 功能操作指南

### 3.1 仪表盘

显示知识库的概览信息：
- 顶部用户信息栏：当前登录用户名、服务器地址
- 统计数据：知识条目总数、工作记录数(按角色过滤)、标签数、关联链接数、收藏数
- 最近更新的条目列表

### 3.2 知识条目管理

#### 查看列表

- 左侧菜单点击「知识条目」进入列表页
- 使用搜索框关键词搜索
- 使用下拉筛选器按「类型」和「标签」筛选
- 标签筛选框（v1.6.0）: 按多级分组树形展示（父标签 ▾ + 缩进子标签），**选择分组父标签时自动匹配该分组全部子标签下的条目**（如选「技能」即含所有 Skill-* 条目）；筛选框已加宽便于查看长名称
- 点击收藏按钮切换收藏筛选

#### 新建条目

1. 在知识条目页点击右上角「+ 新建条目」
2. 填写标题（必填）、摘要、内容
3. 选择类型（笔记/技能/任务/想法/文章）
4. 设置重要性等级（0-5星）
5. 添加标签：输入标签名后回车，点击 × 可移除
6. 点击「保存」

#### 查看详情

- 在列表中点击条目进入详情页
- 详情页显示完整 Markdown 渲染内容
- 左侧显示大纲导航（基于 Markdown 标题自动生成，不少于2个标题时显示）
- 大纲侧边栏支持收起/展开（点击 ✕ 收起，点击 📑 展开）
- 查看关联条目和反向链接
- 查看版本历史（最近5个版本）

#### 编辑条目

- 在详情页点击「编辑」按钮
- 修改内容后保存，自动生成新版本

#### 管理关联

1. 在详情页点击「+ 添加关联」
2. 从列表中选择目标条目
3. 选择关联类型（引用/相关/依赖）

#### 收藏/删除/导出

- 点击「☆ 收藏」/「⭐ 取消收藏」
- 点击「删除」确认后删除
- 点击「📥 导出」下拉选择导出格式（.md / .txt / .doc）
- Word 导出自动生成含标题、作者、时间的样式化文档

#### 分享条目

1. 在详情页点击「🔗 分享」按钮
2. 系统生成分享链接并弹出对话框（同一条目重复点击分享返回相同链接）
3. 点击「复制链接」可发送给他人
4. 分享链接为 HTML 页面（非 JSON），支持大纲导航和导出
5. 点击「停用链接」可撤销分享

> **提示**: 分享链接使用局域网 IP，同一局域网内的设备可直接访问。条目列表和详情页显示分享状态标签（已分享/已停用）。

### 3.3 工作记录管理

#### 查看列表

- 左侧菜单点击「工作记录」进入列表页
- 使用搜索框关键词搜索、类型下拉筛选
- 标签筛选框（v1.6.0）: 多级树形结构，选择分组父标签时自动匹配该分组全部子标签下的记录（如选「日报」即含个人日报/团队日报等）

#### 新建记录

1. 在工作记录页点击「+ 新建记录」
2. 填写标题和内容
3. 选择类型（日记/会议/想法/笔记/任务）
4. 添加标签
5. 点击「保存」

#### 查看/编辑/删除

操作方式与知识条目类似。详情页支持大纲导航（基于 Markdown 标题自动生成），左侧大纲可收起/展开。

#### 转为知识条目

在记录详情页点击「📝 转为知识条目」按钮，系统会自动以该记录内容创建一条新的知识条目，并在新标签页中打开供继续编辑。

### 3.4 标签管理

#### 新建标签

1. 在标签管理页点击「+ 新建标签」
2. 输入标签名称
3. 选择颜色（用于知识图谱显示）
4. 选择父标签（分组）：点击「父标签（分组）」下拉选择上级标签，留空即为顶级标签
5. 点击「保存」

#### 编辑/删除标签

- 点击标签行的「编辑」按钮修改名称、颜色或父标签
- 点击「删除」确认后删除（注意：删除标签不会删除关联的条目；若该标签下有子标签，子标签会自动回到顶级，不会一并删除）

#### 分组展示 (v1.6.0)

- 标签管理页以树形缩进展示分组层级，父标签带「▾/▸」折叠箭头并可点击折叠/展开其下所有子标签
- 折叠状态在同一会话内保持（切换页面再进入依然折叠）
- 所有标签下拉框（条目/记录/搜索/批量操作）按「父标签 → 子标签」分组显示，便于快速定位

> **快捷创建**: 在新建/编辑条目时输入不存在的标签名，系统会自动创建标签（顶级标签）。
> **防循环**: 编辑标签时，下拉中会自动排除自身及其子标签，避免形成循环层级。

### 3.5 知识图谱

#### 查看图谱

- 在左侧菜单点击「知识图谱」
- 节点表示知识条目，连线表示关联关系
- 节点颜色按条目类型区分（蓝色=笔记，橙色=技能，绿色=任务，紫色=想法，粉色=文章）

#### 交互操作

- **拖拽节点**: 鼠标拖拽节点可调整布局，**松开后自动保存布局**（防抖 400ms），下次进入图谱时按保存位置恢复
- **布局边界**: 画布中的**红色虚线大框**即世界坐标护栏范围（±5000，左上角有文字标注）；节点拖到边界会被挡住，框内位置都能完整保存和恢复；缩小视图可看到整个边界框
- **框选多节点**: 按住 **Shift + 空白处拖拽** 拉出矩形选区，松开后选中框内所有节点（蓝色高亮环标记）；多次框选可追加选中
- **整体拖拽**: 框选多个节点后，拖动其中任意一个，**整组节点一起平移**；松开后自动保存整组新布局
- **取消选中**: 单击空白处 或 按 `Esc` 清除当前选区
- **双击节点**: 跳转到对应条目详情页
- **滚轮缩放**: 以鼠标指针为中心缩放视图（20%～300%），指针下的节点不漂移
- **空白拖拽平移**: 按住画布空白处拖动可平移视图（指针变为抓手）
- **缩放控件**: 右下角提供「− / 百分比 / + / ⤢ 重置视图」按钮，重置后回到初始视图
- **视图记忆**: 缩放与平移状态自动保存到浏览器本地，刷新页面后恢复到上次视图位置
- 图例显示在左下角

> **提示**: 只有状态为「活跃」的条目会显示在图谱中。
> 缩放/平移只影响视图，节点保存的仍是原始布局坐标，放大后拖拽保存位置不会错乱。
> 框选在任意缩放/平移状态下都按屏幕实际位置判定，所见即所选框。

> **提示**: 只有状态为「活跃」的条目会显示在图谱中。

### 3.6 智能搜索

#### 基本搜索

1. 在搜索页输入关键词
2. 选择搜索范围（全部/知识条目/工作记录）
3. 实时显示搜索结果，关键词高亮

#### 高级搜索

点击「🔍 高级」展开高级筛选：
- 按标签筛选
- 按日期范围筛选（起始日期 - 结束日期）

#### 搜索技巧

- 搜索词同时匹配标题、内容和摘要
- 日期筛选格式：YYYY-MM-DD

### 3.7 数据管理

#### 从 KB 目录导入 (v1.6.0 / 变更同步 v1.8.0)

1. 在数据管理页点击「📂 从KB目录导入」按钮
2. 系统自动扫描 KB 知识库目录（`D:\1、天翼云盘同步盘\15285514095\KB\`）增量导入
3. 导入完成后显示统计：新增条目数、同步更新条目数、跳过条目数、新增记录数、同步更新记录数、跳过记录数、关联数、标签数、错误数

**目录映射规则**:

| KB 目录 | 导入类型 |
|---------|----------|
| `wiki\` | 知识条目（个人知识） |
| `external-wiki\` | 知识条目（外部知识） |
| `team-wiki\` | 知识条目（团队知识） |
| `skills\` | 技能条目 |
| `outputs\` | 日报记录 |
| `team-outputs\` | 团队日报 |
| `raw\`（含 AIRAW） | 日志记录 |
| `external-raw\` | 资料记录 |

> **增量安全 + 变更同步**: 已存在的标题不会被重复创建或删除；平台记录每个条目的 KB 源文件修改时间，**当 KB 源文件更新时间变化时，重新导入会自动覆盖更新**对应条目/记录内容（首次导入会建立同步基线）。内容无变化则跳过。含乱码（GBK 文件）的数据也会自动修复为正常编码。重复导入安全。

#### 导出数据

1. 在数据管理页点击「导出 JSON」
2. 浏览器会自动下载 JSON 备份文件
3. 文件包含所有条目、记录、标签和关联数据

#### 导入数据

1. 点击「选择文件」按钮选择之前导出的 JSON 文件
2. 点击「导入数据」
3. 系统会将备份数据合并到现有数据中

> **注意**: 导入操作是合并模式，不会清空现有数据。重复数据会根据主键自动忽略。

#### 操作日志

数据管理页面下方显示操作日志列表：

- **日志内容**: 记录导出操作、导入操作，以及条目/记录的创建操作
- **来源标识**: 每条日志标注操作来源（web 或 mobile），通过 `?source=` 参数传递
- **权限控制**: 普通用户仅查看自己的操作日志；管理员可查看全部并清空日志

#### 关于

显示应用版本信息和数据存储说明。

### 3.8 后台管理（仅管理员）

#### 用户管理

1. 在左侧菜单点击「后台管理」
2. 显示用户列表（用户名、角色、创建时间）
3. 点击「+ 添加用户」创建新账户
4. 点击「编辑」修改用户角色或密码
5. 管理员不可删除，普通用户可删除

#### 注册新用户

1. 在登录页点击「注册」选项卡
2. 输入用户名、密码、确认密码
3. 点击「注册」完成创建，之后可用新账户登录

### 3.9 批量操作

知识条目列表和工作记录列表支持批量操作模式，提高数据管理效率。

#### 进入批量模式

1. 在知识条目或工作记录列表页，点击顶部「批量操作」开关按钮
2. 列表每行左侧出现复选框
3. 勾选需要操作的条目/记录（选中项高亮显示）
4. 底部出现批量操作栏，显示已选数量

#### 批量归档

1. 在批量模式下勾选需要归档的条目/记录
2. 点击底部操作栏的「归档」按钮
3. 选中的条目/记录状态变为「已归档」

#### 批量删除

1. 在批量模式下勾选需要删除的条目/记录
2. 点击底部操作栏的「删除」按钮
3. 弹出二次确认对话框：「确定要删除选中的 N 个项目吗？此操作不可恢复。」
4. 点击「确认」后永久删除

#### 批量标签

1. 在批量模式下勾选需要操作的条目/记录
2. 在底部操作栏的标签下拉选中选择一个标签（默认显示"全部标签..."）
3. 点击旁边的「添加标签」按钮，将选中标签应用到所有已选项

> **提示**: 退出批量模式可点击「取消」按钮或再次点击批量模式开关。

### 3.10 附件管理

知识条目和工作记录支持文件附件上传，方便关联相关文档。

#### 上传附件

**方式一：新建时上传**
1. 在新建条目/记录页面，填写完基本信息后
2. 在附件区域点击「选择文件」或拖拽文件到上传区域
3. 选择需要上传的文件（单文件不超过 50MB）
4. 文件上传成功后显示在附件列表中
5. 保存条目/记录后附件自动关联

**方式二：编辑时上传**
1. 在条目/记录详情页点击「编辑」
2. 在编辑页面的附件区域点击「+ 添加附件」
3. 选择文件后上传
4. 保存编辑后附件生效

#### 查看附件

- 在条目/记录详情页中，附件区域位于删除按钮与正文内容之间
- 显示附件列表：文件名、文件大小、上传者、上传时间
- 点击文件名可直接下载

#### 删除附件

1. 在详情页的附件列表中点击附件旁的「删除」按钮
2. 确认后附件被删除（仅创建者可删除自己的附件）

> **注意**: 附件存储在 `data/attachments/` 目录，删除附件会同时删除物理文件。

### 3.11 局域网同步（可选，管理员）

支持 PC 端与手机端在同一局域网内进行数据同步，方便移动办公。

#### 开启同步

PC 端服务启动后，默认监听 0.0.0.0:8080 端口，局域网内设备可通过 `http://192.168.x.x:8080` 访问。

#### 手机端连接

1. 确保手机与 PC 连接同一 WiFi 网络
2. 在手机端浏览器或知识库 App 中输入 PC 的局域网 IP 地址
3. 使用已有账户登录（需先在 PC 端创建账户）
4. 连接成功后即可远程查看、创建条目和记录

#### 远程数据交换

- **远程导出**: 手机端可从 PC 端拉取数据备份（JSON 格式）
- **远程导入**: 手机端可将本地数据推送至 PC 端合并
- **远程管理**: 手机端可创建条目和记录，同步到 PC 端

> **提示**: 局域网同步功能默认开启，无需额外配置。如需关闭可修改启动参数限制为 127.0.0.1。

## 5. 常见问题

### Q: 管理员账户是什么？

A: 用户名 `admin`。管理员口令通过本机用户环境变量 `KNOWLEDGE_ADMIN_PASS` 提供，不写入文档；建议定期轮换。首次安装新库时随机初始口令会输出在启动日志。

### Q: 如何备份数据？

A: 在「数据管理」页面使用导出功能，将数据保存为 JSON 文件。也可直接备份 `data/knowledge.db` 文件。

### Q: 数据安全吗？

A: 所有数据存储在本地 SQLite 数据库中，服务仅监听 127.0.0.1（本机回环地址），不对外网开放。

### Q: 支持 Markdown 吗？

A: 支持基础 Markdown 语法：标题(# ## ###)、加粗(**)、斜体(*)、代码块(```)、行内代码(`)、引用(>)、列表(-)、数字列表(1.)

### Q: 双链如何工作？

A: 在条目详情页可以添加「关联条目」，添加后会自动建立双向链接。关联的条目会显示在条目的「关联条目」和「反向链接」区域。

### Q: 如何完全清除数据？

A: 删除 `data/` 目录下的所有文件，重启服务后会自动重新初始化。

### Q: 数据文件在哪？

A: 数据库文件位于项目根目录的 `data/knowledge.db`，附件文件位于 `data/attachments/`。

### Q: 操作日志记录了哪些内容？

A: 数据导出/导入操作、知识条目和工作记录的创建操作，均记录操作用户、时间、来源（web/mobile）及详情。
