你的知识，本地优先

KnowledgePC 是一个单机部署、局域网可用的个人知识管理平台 —— Markdown 条目、双向链接、知识图谱、标签树，数据完全掌握在自己手中。

GitHub 仓库 快速开始
Java 17 SQLite WAL 零框架后端 无构建前端 MIT License

核心功能

一个轻量但完整的个人知识库解决方案

📝

知识条目

Markdown 编辑、大纲导航、版本历史、收藏与公开分享链接。

🗂️

工作记录

日报、会议纪要、灵感想法分类记录，与知识条目相互独立。

🔗

双链笔记

[[页面名]] 与 [[目录/页面名]] 语法，导入时自动建立双向链接索引。

🕸️

知识图谱

Canvas 力导向图可视化关联网络，支持节点拖拽与布局记忆。

🏷️

标签体系

层级标签树、颜色管理、批量打标，多维度组织知识。

🔄

KB 目录同步

监控 wiki 目录，按文件修改时间增量导入，支持全量重建双链。

🔐

用户与安全

PBKDF2 密码哈希、角色权限、会话过期、CSP 与路径穿越防护。

💾

备份迁移

JSON 全量导出/导入，包含图谱布局坐标，换机不丢数据。

技术架构

极简依赖，一台装了 JDK 的电脑就能跑

Java 17 · 内置 HttpServer 无框架
SQLite · WAL 模式单文件数据库
原生 JS · 零构建零 npm
Gradle · Wrapper 一键编译

快速开始

三步启动，浏览器访问 http://127.0.0.1:8080

Windows（Linux/macOS 使用对应 .sh 脚本）
# 1. 克隆仓库（需 JDK 17+）
git clone https://github.com/wangjlx/KnowledgePC.git
cd KnowledgePC

# 2. 编译
compile.bat

# 3. 启动
start.bat
