# 知识库 数据库字典

**数据库引擎**: SQLite
**数据库文件**: data/knowledge.db (项目 data 目录)
**版本**: v5
**表数量**: 13

---

## 1. 用户表 (users)

系统用户账户信息。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| username | TEXT | UNIQUE, NOT NULL | 用户名 |
| password | TEXT | NOT NULL | 密码哈希。v1.8.4 起 PBKDF2-HmacSHA256 格式 `pbkdf2$120000$saltB64$hashB64`；历史无盐 SHA-256(64位hex) 在该用户下次登录成功时自动升级 |
| role | TEXT | DEFAULT 'user', CHECK | 角色: admin(管理员)/user(普通用户) |
| created_at | DATETIME | DEFAULT (datetime('now','localtime')) | 创建时间 |

**默认账户**: 用户名 `admin`（口令不写入文档，通过用户环境变量 `KNOWLEDGE_ADMIN_PASS` 提供；新库首次初始化时随机口令输出在启动日志）

---

## 2. 知识条目表 (knowledge_entries)

知识资产的核心实体表，存储所有知识条目。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| title | TEXT | NOT NULL | 标题 |
| content | TEXT | DEFAULT '' | Markdown 内容 |
| summary | TEXT | DEFAULT '' | 摘要 |
| entry_type | TEXT | DEFAULT 'note', CHECK | 类型: note/skill/task/idea/article |
| status | TEXT | DEFAULT 'active', CHECK | 状态: active(活跃)/archived(归档) |
| importance | INTEGER | DEFAULT 0 | 重要性: 0-5 |
| created_by | TEXT | DEFAULT '' | 创建人用户名 |
| created_at | DATETIME | DEFAULT (datetime('now','localtime')) | 创建时间 |
| updated_at | DATETIME | DEFAULT (datetime('now','localtime')) | 更新时间 |
| kb_source | TEXT | DEFAULT '' | KB 源文件相对路径（相对 KB 根目录，`/` 分隔，v1.8.0） |
| kb_mtime | TEXT | DEFAULT '' | KB 源文件最后修改时间（毫秒时间戳字符串，v1.8.0，用于判断是否需重新同步） |

**索引**:
- idx_entries_title ON title
- idx_entries_type ON entry_type
- idx_entries_status ON status
- idx_entries_updated ON updated_at

> **v1.8.0**: 新增 `kb_source` / `kb_mtime` 列。KB 目录导入时记录源文件路径与修改时间，重新导入若源文件 mtime 变化则覆盖更新条目内容。历史库通过 `ALTER TABLE ADD COLUMN` 自动迁移。

---

## 3. 标签表 (tags)

标签分类体系。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| name | TEXT | UNIQUE, NOT NULL | 标签名称 |
| color | TEXT | DEFAULT '#1a73e8' | 标签颜色(十六进制) |
| parent_id | INTEGER | REFERENCES tags(id) ON DELETE SET NULL | 父标签（分组），0/NULL=顶级标签 |
| created_at | DATETIME | DEFAULT (datetime('now','localtime')) | 创建时间 |

> **v1.6.0**: 新增 `parent_id` 实现标签分组管理。删除父标签时子标签 `parent_id` 自动置 NULL 回到顶级（不级联删除数据）。

---

## 4. 条目-标签关联表 (entry_tags)

知识条目与标签的多对多关系。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| entry_id | INTEGER | PK, FK→knowledge_entries(id) ON DELETE CASCADE | 条目ID |
| tag_id | INTEGER | PK, FK→tags(id) ON DELETE CASCADE | 标签ID |

---

## 5. 条目关联表 (entry_links)

知识条目之间的双向链接（双链关联的核心表）。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| source_id | INTEGER | NOT NULL, FK→knowledge_entries(id) ON DELETE CASCADE | 源条目ID |
| target_id | INTEGER | NOT NULL, FK→knowledge_entries(id) ON DELETE CASCADE | 目标条目ID |
| link_type | TEXT | DEFAULT 'reference', CHECK | 类型: reference/dependency/related |
| created_at | DATETIME | DEFAULT (datetime('now','localtime')) | 创建时间 |
| UNIQUE | (source_id, target_id) | 防止重复链接 |

**索引**:
- idx_links_source ON source_id
- idx_links_target ON target_id

---

## 6. 条目版本表 (entry_versions)

知识条目的版本历史记录。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| entry_id | INTEGER | NOT NULL, FK→knowledge_entries(id) ON DELETE CASCADE | 条目ID |
| title | TEXT | NOT NULL | 当时的标题 |
| content | TEXT | DEFAULT '' | 当时的内容 |
| version | INTEGER | NOT NULL | 版本号(递增) |
| change_summary | TEXT | DEFAULT '' | 变更摘要 |
| created_at | DATETIME | DEFAULT (datetime('now','localtime')) | 版本创建时间 |

**索引**: idx_versions_entry ON entry_id

---

## 7. 工作记录表 (work_records)

日常碎片化工作记录。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| title | TEXT | NOT NULL | 标题 |
| content | TEXT | DEFAULT '' | 内容 |
| record_type | TEXT | DEFAULT 'daily', CHECK | 类型: daily/meeting/idea/note/task |
| voice_path | TEXT | NULL | 语音文件路径(保留字段) |
| duration | INTEGER | DEFAULT 0 | 语音时长(秒，保留字段) |
| status | TEXT | DEFAULT 'active', CHECK | 状态: active/completed/archived |
| importance | INTEGER | DEFAULT 0 | 重要性: 0-5 |
| created_by | TEXT | DEFAULT '' | 创建人用户名 |
| created_at | DATETIME | DEFAULT (datetime('now','localtime')) | 创建时间 |
| updated_at | DATETIME | DEFAULT (datetime('now','localtime')) | 更新时间 |
| kb_source | TEXT | DEFAULT '' | KB 源文件相对路径（相对 KB 根目录，`/` 分隔，v1.8.0） |
| kb_mtime | TEXT | DEFAULT '' | KB 源文件最后修改时间（毫秒时间戳字符串，v1.8.0，用于判断是否需重新同步） |

**索引**:
- idx_records_type ON record_type
- idx_records_updated ON updated_at

> **v1.8.0**: 新增 `kb_source` / `kb_mtime` 列。KB 目录导入时记录源文件路径与修改时间，重新导入若源文件 mtime 变化则覆盖更新记录内容。历史库通过 `ALTER TABLE ADD COLUMN` 自动迁移。

## 11. 图谱布局表 (graph_layouts)

知识图谱节点手动拖拽后的位置记录（v1.6.0 新增）。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| entry_id | INTEGER | PK, FK→knowledge_entries(id) ON DELETE CASCADE | 条目ID（图谱节点） |
| x | REAL | DEFAULT 0 | 节点 X 坐标 |
| y | REAL | DEFAULT 0 | 节点 Y 坐标 |
| updated_at | DATETIME | DEFAULT (datetime('now','localtime')) | 更新时间 |

> **保存策略**: 前端拖拽结束后防抖 400ms 整体覆盖保存（先清空再批量插入）；读取时未保存或坐标非法（非数值/超出护栏 ±5000）的节点回落环形自动布局。坐标允许负值（节点可拖出画布/原点，v1.8.1）；拖拽写入值已被前端钳制在 ±5000 内（v1.8.2，画布红色虚线框同步显示该范围）。

---

## 12. 分享表 (shares)

知识条目的分享链接记录。POST 创建时自动检测是否有活跃分享，有则直接返回现有记录。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| entry_id | INTEGER | NOT NULL, FK→knowledge_entries(id) ON DELETE CASCADE | 共享条目ID |
| share_token | TEXT | UNIQUE, NOT NULL | 分享令牌(32位hex；v1.8.4 前为16位) |
| is_active | INTEGER | DEFAULT 1 | 状态: 1=活跃(启用), 0=停用 |
| created_by | TEXT | DEFAULT '' | 分享创建人 |
| created_at | DATETIME | DEFAULT (datetime('now','localtime')) | 创建时间 |

**索引**: idx_shares_token ON share_token

---

## 13. 附件表 (attachments)

知识条目和工作记录的文件附件存储。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| source_type | TEXT | NOT NULL, CHECK | 关联类型: entry(条目)/record(记录) |
| source_id | INTEGER | NOT NULL | 关联条目/记录ID |
| filename | TEXT | NOT NULL | 原始文件名 |
| filepath | TEXT | NOT NULL | 服务器存储路径 |
| file_size | INTEGER | DEFAULT 0 | 文件大小(字节) |
| mime_type | TEXT | DEFAULT '' | MIME 类型 |
| created_by | TEXT | DEFAULT '' | 上传者用户名 |
| created_at | DATETIME | DEFAULT (datetime('now','localtime')) | 上传时间 |

**索引**:
- idx_attach_source ON (source_type, source_id)

---

## 14. 操作日志表 (operation_logs)

记录数据管理相关的操作（导出、导入、条目/记录创建），用于审计追溯。

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| operation | TEXT | NOT NULL | 操作类型: export/import/create_entry/create_record |
| detail | TEXT | DEFAULT '' | 操作详情(JSON格式，包含标题、数量等) |
| username | TEXT | NOT NULL | 操作人用户名 |
| source | TEXT | DEFAULT 'web' | 来源: web(浏览器)/mobile(移动端) |
| created_at | DATETIME | DEFAULT (datetime('now','localtime')) | 操作时间 |

**索引**:
- idx_oplogs_operation ON operation
- idx_oplogs_username ON username
- idx_oplogs_created ON created_at

## 15. 实体关系图 (ER)

```
users (通过 created_by 文本字段关联条目/记录)

knowledge_entries ──1:N── entry_tags ──N:1── tags
       │                                      │
       │ 1:N                                  │ 1:N
       │                                      │
       ├── entry_links (source)               │
       ├── entry_links (target)               │
       │                                      │
       ├──1:N── entry_versions                │
       │                                      │
       ├── favorites                          │
       │                                      │
       ├──1:N── shares                        │
       │                                      │
       ├──1:N── attachments (source_type='entry')
       │                                      │
       └──1:N── record_links ──N:1── work_records
                                               │
                                               ├──1:N── attachments (source_type='record')
                                               │
                                               └──1:N── record_tags ──N:1── tags

operation_logs (独立表，按操作人/操作类型/时间查询)
```

> 注: users 表独立维护，条目/记录通过 `created_by` 文本字段记录创建人用户名，不设外键约束。
> operation_logs 独立记录操作审计信息，不与其他表建立外键约束。

## 17. 建表 DDL

```sql
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL,
  role TEXT DEFAULT 'user' CHECK(role IN ('admin','user')),
  created_at DATETIME DEFAULT (datetime('now','localtime'))
);

CREATE TABLE knowledge_entries (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  content TEXT DEFAULT '',
  summary TEXT DEFAULT '',
  entry_type TEXT DEFAULT 'note' CHECK(entry_type IN ('note','skill','task','idea','article')),
  status TEXT DEFAULT 'active' CHECK(status IN ('active','archived')),
  importance INTEGER DEFAULT 0,
  created_by TEXT DEFAULT '',
  created_at DATETIME DEFAULT (datetime('now','localtime')),
  updated_at DATETIME DEFAULT (datetime('now','localtime')),
  kb_source TEXT DEFAULT '',
  kb_mtime TEXT DEFAULT ''
);

CREATE TABLE tags (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT UNIQUE NOT NULL,
  color TEXT DEFAULT '#1a73e8',
  parent_id INTEGER REFERENCES tags(id) ON DELETE SET NULL,
  created_at DATETIME DEFAULT (datetime('now','localtime'))
);

CREATE TABLE entry_tags (
  entry_id INTEGER NOT NULL REFERENCES knowledge_entries(id) ON DELETE CASCADE,
  tag_id INTEGER NOT NULL REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY(entry_id, tag_id)
);

CREATE TABLE entry_links (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  source_id INTEGER NOT NULL REFERENCES knowledge_entries(id) ON DELETE CASCADE,
  target_id INTEGER NOT NULL REFERENCES knowledge_entries(id) ON DELETE CASCADE,
  link_type TEXT DEFAULT 'reference' CHECK(link_type IN ('reference','dependency','related')),
  created_at DATETIME DEFAULT (datetime('now','localtime')),
  UNIQUE(source_id, target_id)
);

CREATE TABLE entry_versions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  entry_id INTEGER NOT NULL REFERENCES knowledge_entries(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  content TEXT DEFAULT '',
  version INTEGER NOT NULL,
  change_summary TEXT DEFAULT '',
  created_at DATETIME DEFAULT (datetime('now','localtime'))
);

CREATE TABLE work_records (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  content TEXT DEFAULT '',
  record_type TEXT DEFAULT 'daily' CHECK(record_type IN ('daily','meeting','idea','note','task')),
  voice_path TEXT,
  duration INTEGER DEFAULT 0,
  status TEXT DEFAULT 'active' CHECK(status IN ('active','completed','archived')),
  importance INTEGER DEFAULT 0,
  created_by TEXT DEFAULT '',
  created_at DATETIME DEFAULT (datetime('now','localtime')),
  updated_at DATETIME DEFAULT (datetime('now','localtime')),
  kb_source TEXT DEFAULT '',
  kb_mtime TEXT DEFAULT ''
);

CREATE TABLE record_tags (
  record_id INTEGER NOT NULL REFERENCES work_records(id) ON DELETE CASCADE,
  tag_id INTEGER NOT NULL REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY(record_id, tag_id)
);

CREATE TABLE record_links (
  record_id INTEGER NOT NULL REFERENCES work_records(id) ON DELETE CASCADE,
  entry_id INTEGER NOT NULL REFERENCES knowledge_entries(id) ON DELETE CASCADE,
  PRIMARY KEY(record_id, entry_id)
);

CREATE TABLE favorites (
  entry_id INTEGER NOT NULL REFERENCES knowledge_entries(id) ON DELETE CASCADE,
  created_at DATETIME DEFAULT (datetime('now','localtime')),
  PRIMARY KEY(entry_id)
);

CREATE TABLE graph_layouts (
  entry_id INTEGER NOT NULL REFERENCES knowledge_entries(id) ON DELETE CASCADE,
  x REAL NOT NULL DEFAULT 0,
  y REAL NOT NULL DEFAULT 0,
  updated_at DATETIME DEFAULT (datetime('now','localtime')),
  PRIMARY KEY(entry_id)
);

CREATE TABLE shares (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  entry_id INTEGER NOT NULL REFERENCES knowledge_entries(id) ON DELETE CASCADE,
  share_token TEXT UNIQUE NOT NULL,
  is_active INTEGER DEFAULT 1,
  created_by TEXT DEFAULT '',
  created_at DATETIME DEFAULT (datetime('now','localtime'))
);

CREATE INDEX idx_shares_token ON shares(share_token);

CREATE TABLE attachments (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  source_type TEXT NOT NULL CHECK(source_type IN ('entry','record')),
  source_id INTEGER NOT NULL,
  filename TEXT NOT NULL,
  filepath TEXT NOT NULL,
  file_size INTEGER DEFAULT 0,
  mime_type TEXT DEFAULT '',
  created_by TEXT DEFAULT '',
  created_at DATETIME DEFAULT (datetime('now','localtime'))
);

CREATE TABLE operation_logs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  operation TEXT NOT NULL,
  detail TEXT DEFAULT '',
  username TEXT NOT NULL,
  source TEXT DEFAULT 'web',
  created_at DATETIME DEFAULT (datetime('now','localtime'))
);

CREATE INDEX idx_oplogs_operation ON operation_logs(operation);
CREATE INDEX idx_oplogs_username ON operation_logs(username);
CREATE INDEX idx_oplogs_created ON operation_logs(created_at);
```
